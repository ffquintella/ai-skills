# Color palette

The single place that defines colors. To match a brand, change the hex values here and
nothing else. Color encodes meaning, so reuse a category's pair for everything of that kind.
Always pair a dark stroke with a light fill.

## Shapes (fill / stroke)

| Meaning | Fill | Stroke |
| --- | --- | --- |
| Primary / neutral | `#3b82f6` | `#1e3a5f` |
| Secondary | `#60a5fa` | `#1e3a5f` |
| Tertiary | `#bfdbfe` | `#1e3a5f` |
| Start / trigger | `#fed7aa` | `#c2410c` |
| End / success | `#a7f3d0` | `#047857` |
| Decision | `#fef3c7` | `#b45309` |
| AI / model | `#ddd6fe` | `#6d28d9` |
| Warning / reset | `#ffe4e6` | `#be123c` |
| Error | `#fecaca` | `#b91c1c` |
| Inactive / disabled | `#e2e8f0` | `#64748b` (dashed stroke) |

## Text

| Use | Color |
| --- | --- |
| Title | `#1e40af` |
| Subtitle | `#3b82f6` |
| Body / detail (free-floating) | `#64748b` |
| On a light fill | `#1f2937` |
| On a dark fill | `#ffffff` |

## Evidence artifacts (code, data)

- Code or payload box: fill `#1e293b`, stroke `#0f172a`.
- JSON / data text: `#22c55e`. Code text: `#e2e8f0`; keywords `#c4b5fd`, strings `#fcd34d`.

## Lines and background

- Arrows take the stroke color of their source element.
- Structural lines (dividers, trees, timelines): `#1e3a5f` or `#64748b`.
- Marker dots: fill `#3b82f6`, same stroke.
- Canvas background: `#ffffff`.
